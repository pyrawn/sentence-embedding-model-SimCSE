# sentence-embedding-model-SimCSE

A replication of **SimCSE** (Gao, Yao & Chen, EMNLP 2021,
[arXiv 2104.08821](https://arxiv.org/abs/2104.08821)), in both its
unsupervised and supervised forms. Both models fine-tune `bert-base-uncased`
on a 100k-record subset of SNLI and are evaluated on STS-B (cosine
similarity, Spearman ×100, no STS-B fine-tuning). Course assignment U2T02,
Trends in Data Science.

**Main deliverable: [reports/report.md](reports/report.md)**. It contains
the conceptual answers, the configuration, the benchmark, the ablations, the
gap to the paper, the optional extensions and the published models.

## Published models

| Model (Hugging Face Hub) | Mode | STS-B dev | STS-B test |
|---|---|---|---|
| [pyrawn/simcse-bert-base-snli-unsup](https://huggingface.co/pyrawn/simcse-bert-base-snli-unsup) | Unsupervised (dropout as augmentation) | 76.92 | **68.33** |
| [pyrawn/simcse-bert-base-snli-sup](https://huggingface.co/pyrawn/simcse-bert-base-snli-sup) | Supervised (entailment positives + contradiction hard negatives) | 82.05 | **78.75** |

For reference, on the same harness: raw `bert-base-uncased` (mean pooling)
scores 59.31 / 47.29, and SBERT-2019 (`bert-base-nli-mean-tokens`) scores
80.77 / 76.98. The paper reports 82.5 / 76.85 (unsup) and 86.2 / 84.25
(sup). Full table: [reports/benchmark_table.md](reports/benchmark_table.md).
Gap explanation: [reports/gap_analysis.md](reports/gap_analysis.md).

Both models load as `sentence-transformers` models:

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("pyrawn/simcse-bert-base-snli-sup")
emb = model.encode(["A man is playing a guitar.", "Someone plays an instrument."])
```

## Reproducing

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # pinned versions
```

The execution order follows the dependency graph in
[handoffs/00_INDEX.md](handoffs/00_INDEX.md), not the part numbering.
See that file for the full details (Kaggle workflow, run-log schema,
conventions).

1. **Data prep (local):** `python src/data_prep.py`. This builds
   `data/processed/` and `data/stsb/`, and writes counts and sha256
   checksums to `data/processed/MANIFEST.json`. The process is
   deterministic. The counts must match the expected values in
   [handoffs/02_part2_data_prep.md](handoffs/02_part2_data_prep.md)
   (165,529 sentences / 33,351 pairs / ~28% with a hard negative /
   1,500 dev / 1,379 test).
2. **Evaluation sanity check (local, before any training):**
   `python src/evaluate.py --reference`. It must reproduce raw BERT
   (59.31 / 47.29) and SBERT-2019 (80.77 / 76.98) within ±1.
3. **Training (Kaggle GPU; there is no local GPU):** run
   `kaggle/build_*_dataset.sh` and upload the zip from `kaggle/dist/` as a
   Kaggle Dataset. Then run the matching `kaggle/*.ipynb` with GPU and
   Internet enabled. The notebooks call
   `train_simcse.py --mode unsup|sup --config <config>`. Copy each
   `runs/<run_id>/` back locally and append its `run_record.json` to
   `runs/run_log.jsonl`. The ablations use the same workflow with
   `configs/ablation_*.json`.
4. **Analysis and benchmark (local):** `python src/eval_analysis.py`
   (alignment/uniformity, plots, retrievals on dev). Then run
   `python src/benchmark.py --score-test` **once**, since it refuses to
   re-score test. Then `python src/benchmark.py` writes the table.
5. **Publish (local, needs `HF_TOKEN`):** `python src/publish.py`
   `export → push → verify → record`, once per model (see the docstring of
   `src/publish.py`).

STS-B test is scored exactly once per checkpoint. Checkpoints are always
selected on dev.
